# Japanese Lesson 2 — Images

Upload the vocabulary-card images for this downloadable deck here.

Suggested filenames:

- `kochira.jpg` — こちら
- `tomodachi.jpg` — 友達（ともだち）
- `kare.jpg` — 彼（かれ）
- `kanojo.jpg` — 彼女（かのじょ）
- `gakusei.jpg` — 学生（がくせい）
- `watashitachi.jpg` — 私たち（わたしたち）
- `dare.jpg` — 誰（だれ）

PNG, JPG/JPEG, and WebP are suitable. The course JSON can be wired to the final filenames after the images are uploaded.
