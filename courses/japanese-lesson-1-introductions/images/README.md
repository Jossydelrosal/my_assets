# Japanese Lesson 1 images

Upload vocabulary-card artwork for `Japanese Lesson 1 — Introductions & Nationalities` to this folder.

Recommended filenames use the authored card IDs without the `word-` prefix, for example:

- `konnichiwa.jpg`
- `hajimemashite.jpg`
- `yoroshiku-onegaishimasu.jpg`
- `watashi.jpg`
- `nihon.jpg`
- `nihonjin.jpg`

PNG, JPG/JPEG, and WebP are all suitable. The course JSON will reference these files with paths such as `images/nihon.jpg` after the artwork is uploaded.
